# Rose Night Animation

A modified version of the original Flower project.

Animation sequence:
1. Intro text fades in.
2. Text fades out.
3. A hand-drawn-style rose bouquet grows and blooms.
4. Background stars appear.
5. A meteor shower begins.

## Files

- `index.html` - page structure
- `style.scss` - editable SCSS source and animation definitions
- `style.css` - browser-ready compiled CSS used by the page
- `main.js` - starts the animation after the page loads

The page is static HTML/CSS/JS and can be hosted with GitHub Pages.
